a) get() -- Opens the specified URL in the current browser window and waits until the page is fully loaded.

b) getCurrentURL() -- Returns the complete URL of the web page currently displayed in the browser.

c) getPageSource()-- Returns the HTML source code of the current web page as a string.

d) getTitle() -- Returns the title of the current web page.

e) close() vs quit() -- close() closes only the current browser window, whereas quit() closes all open browser windows and ends the WebDriver session.

f) getWindowHandle() -- Returns the unique identifier (handle) of the currently active browser window.

g) getWindowHandles() -- Returns a set of unique identifiers for all open browser windows.

h) navigate() -- Provides navigation commands such as to(), back(), forward(), and refresh() to control browser history.

i) switchTo() -- Used to switch the driver's focus to another window, frame, or alert.
